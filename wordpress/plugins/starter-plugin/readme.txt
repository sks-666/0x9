A bare custom plugin scaffold to build from.

== Description ==

Starting point for a custom WordPress plugin. Ships with a single sample
shortcode (`[starter_plugin_hello]`) and activation/deactivation hook
stubs — replace with real functionality as the plugin grows.

== Installation ==

1. Copy this directory into `wp-content/plugins/`.
2. Activate "Starter Plugin" from the WordPress admin Plugins screen, or
   run `wp plugin activate starter-plugin` via WP-CLI.
